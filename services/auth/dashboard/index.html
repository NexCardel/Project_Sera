🛠️ How to test the Sera SDC extension locally:

  1. Open a terminal and start a local Python server in the root APP directory:
    cd "c:\Users\Nex\Downloads\Project Sera\APP"
    python -m http.server 8000
  2. Navigate to http://localhost:8000/services/auth/dashboard/ in your browser. This URL path now exactly mirrors the real GST portal's dashboard URL.
  3. You should immediately see the SDC Toast popup indicating the GST Calendar captures were buffered into memory.
  4. Click the red "Log out" button at the top right.
  5. The SDC Instant Logout interceptor will trigger, immediately flush the atomic payload to the background python server without exceeding the 64KB limit, and then the page will redirect!
  6. Check the Sera Desktop App's Tracker Dump table.

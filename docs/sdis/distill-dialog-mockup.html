Sera Distill — the Distill… dialog

Design for W4-5 (blueprint Part L). Tracker dump → Tools ▾ → Distill…, admin PC only. Same dark theme and green accent as the Tracker Dump window. All values below are fictional. The aim is the opposite of the SGT lab: one calm list of datapoints, every number a percentage, each datapoint shown once, and the containers always in view on the right.

A · Main view (Datapoints tab), one datapoint expanded, "Add to" menu open

Non-modal window, opens at 1280×800, resizable; the side panel is collapsible (≡ in the title row). Opening it never starts mining.

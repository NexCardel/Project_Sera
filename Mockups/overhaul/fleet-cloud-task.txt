DESIGN RULES
- Keep every control. Each control in a screenshot appears in your design: moved, regrouped, relabelled or put in a menu is fine; dropped is not.
- Dark theme only. Emerald #2E9B5F is the one primary action colour per screen; red only for destructive actions. Data grids stay highly readable (the white grid is the owner's preference; argue for a change if you have one).
- Small laptop first: every screen works at 1366x768, with no sideways scroll except inside a data grid.
- Fictional data only: made-up client names, PANs like ABCDE1234F, made-up workstation names. Secrets always appear masked.
- Build it the way the app can follow. Use one :root token block (colours, radii 6/8/12, spacing, font sizes, control height) and a small set of reusable components: chip, switch, card, pill, tag, labelled action, setting row, status strip, selection bar, unsaved bar, empty state. Make every screen only from those, because it will be rebuilt in Qt from them.
- No new product features. Put any ideas in the README under Ideas instead of drawing them.
- The logo is assets/logo/sera_mark.svg. Embed it as is; do not redraw it.
